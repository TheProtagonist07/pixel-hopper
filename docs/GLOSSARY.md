# Glossary

Short definitions of the terms used in the code and the docs, in alphabetical order.

| Term | Meaning |
|---|---|
| **9-slice** | Drawing a panel from a small texture cut into 3 x 3 parts: corners keep their size, edges stretch one way, the middle stretches both ways. Lets a panel be any size without distorted corners. (`UiKit.NineSlice`) |
| **Alpha** | Opacity of a colour or pixel: 0 invisible, 1 solid. |
| **Ambient particles** | Decorative drifting particles (snow, leaves, embers, fireflies, rain). (`AmbientParticles`) |
| **Atlas** | One large texture holding many small sprites, so they can be drawn together in few draw calls. (`PixelArt`) |
| **Bake** | Turn painted shapes into a finished texture. (`PixelPainter.Bake`) |
| **Bayer matrix / ordered dithering** | A fixed 4 x 4 threshold pattern used to blend between two colours as a regular pixel pattern instead of a smooth gradient. Gives the sky and banner their retro look. |
| **Bulge** | How round a painted shape looks (0 flat, 1 full sphere). |
| **Chunk** | A short hand-designed piece of level (gap, wall, spikes...) that starts and ends on flat ground. Stages are chains of chunks. |
| **Coyote time** | A short grace period (0.1 s) after walking off a ledge during which jumping still works. |
| **Decor** | Scenery props on the ground (bushes, cacti...) that have no collision. |
| **Deterministic** | Always produces the same result for the same input. Stages and backgrounds use fixed random seeds. |
| **Dithering** | Mixing two colours in a pixel pattern to fake in-between shades. |
| **Domain reload** | Unity re-loading all scripts after a compile; it wipes runtime-created objects, which is why you must not edit scripts in Play mode. |
| **Execution order** | Which script's `Update` runs first. `Game` uses -100, `Backdrop` 100. |
| **Extrusion** | Copying a shape down-right in a darker shade to fake depth. Used by the 3D logo. |
| **Grid / LevelGrid** | The 2D array of characters that describes a stage. |
| **Hit box** | A trigger collider used to detect touching (enemy hit box, spike hurt box). |
| **IMGUI / OnGUI** | Unity's old immediate-mode UI. Not used here because of washed-out colours. |
| **Immediate mode** | UI that is redrawn every frame by function calls instead of persistent objects. |
| **Invulnerability** | The 2 seconds after respawning when hits are ignored; the hero blinks. |
| **itch.io** | The website where the game is published. |
| **Jump buffering** | Remembering a jump press for 0.12 s so pressing slightly before landing still jumps. |
| **Letterbox / pillarbox** | Black bars above and below / left and right of the game when the window is not 9:16. |
| **Linear colour space** | Unity colour mode in which lighting maths is physically based; it exposed the IMGUI colour problem. |
| **LateUpdate** | Unity callback after all `Update` calls; used for camera, backdrop and UI. |
| **Normal** | The direction a surface faces; used by `PixelPainter` for lighting. |
| **Parallax** | Background layers moving slower than the camera to suggest depth. |
| **Pivot** | The point of a sprite that is placed at its position (feet or centre). |
| **Pixel snapping** | Rounding positions to whole sprite pixels (1/32 unit) so pixel art does not shimmer. |
| **PlayerPrefs** | Unity's simple saved settings (browser local storage on the web). Used for "help skipped". |
| **PPU (pixels per unit)** | Sprite pixels per world unit: 32. One tile is 32 pixels. |
| **Procedural** | Generated by code rather than stored as a file. |
| **Specular** | A bright glint where a surface reflects the light toward the viewer. |
| **Squash and stretch** | Animation principle: scaling a sprite taller or flatter on jump and landing for a bouncy feel. |
| **Stomp** | Landing on an enemy from above: kills it and bounces the hero. |
| **Surface** | The row of tiles the hero walks on (row 3). |
| **Template (WebGL)** | The HTML page Unity wraps around the game build. |
| **Tint** | A colour multiplied onto a sprite to recolour it for a world. |
| **Tone band** | One of four brightness levels used when lighting sprites (deep shadow, shade, base, highlight). |
| **Trigger** | A collider that detects overlap but does not block movement. |
| **uGUI** | Unity's canvas-based UI system; the game draws its UI on one canvas. |
| **Variable jump height** | Releasing the jump button early cuts the jump short. |
| **Viewport / ViewRect** | The 9:16 screen rectangle where the game is drawn. |
| **WebGL** | The browser graphics API; "WebGL build" means the browser version of the game. |
